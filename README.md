# 2048-game
A Python-based 2048 game where players combine matching numbered tiles to reach the 2048 tile. The game uses keyboard controls, random tile generation, score tracking, and movement logic. This project helped me practice Python fundamentals, loops, functions, lists, conditions, and game logic while building an interactive console-based game.
Main features
🎮 4×4 game board
⌨️ W/A/S/D keyboard controls
🎲 Random generation of new 2 tiles
🔄 Tile movement in all four directions
➕ Automatic merging of matching tiles
🏆 Detects when the player reaches 2048
❌ Detects when no more moves are possible
🚫 Handles invalid keyboard input
🐍 Built completely using Python
📦 Uses Python's built-in random module
